Goal: Web app for Van Cortlandt Park’s bench adoption program: More than 500 benches across the park. Donors can adopt benches for a specific number of months, upto 1 year. Website displays current and next calendar year for reservations

Stack: Hosted on Vercel with Next.JS for front end (tailwind, typescript) /backend (Node.JS) + Supabase. Git for version control. Claude Code for building.

Pages: Home, Reservations, Account, Admin, Login/Signup(popup window)
